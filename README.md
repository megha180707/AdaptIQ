
# AdaptIQ

> AI-Powered Adaptive Assessment & Personalized Learning Platform

![Status](https://img.shields.io/badge/status-MVP-blue)
![Next.js](https://img.shields.io/badge/Next.js-16-black)
![Supabase](https://img.shields.io/badge/Supabase-PostgreSQL-green)

## Problem

Traditional online assessments give identical question sequences to every learner. As a result, teachers only receive aggregate scores while students receive little insight into their actual misconceptions.

**AdaptIQ** solves this through AI-powered adaptive questioning, concept-wise mastery tracking, Elo-inspired skill estimation, and personalized remediation.

## Core Approach

AdaptIQ separates deterministic assessment logic from Generative AI.

### Adaptive Engine

- Student skill estimation
- Difficulty routing
- Mastery calculation
- Performance tracking

### AI Layer

- Question generation
- Explanations
- Personalized hints
- Learning-gap interpretation
